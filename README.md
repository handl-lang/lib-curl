# lib-curl

sdkgen-generated libcurl FFI bindings — generic ports plus the
`c-linux-x86_64` adapters, emitted under `handl-packages/generated/` (a
gitignored build artifact). The spec (`specs/curl.h`) re-declares the easy +
multi entry points because `hnl sdkgen c` only collects main-file decls.

## Layout

```text
src/        the .hnl sources
specs/      committed sdkgen inputs (curl.h spec + curl.sdkgen.yaml config)
handl-packages/generated/   build artifact — regenerated by the gate
pkg.hnl     dependencies, when any: `{ deps: { <name>: "branch:<ref>" } }`
```

## Regenerate

```bash
hnl sdkgen c specs/curl.h \
  --output handl-packages/generated/curl \
  --config specs/curl.sdkgen.yaml
```

(needs libclang — set `LIBCLANG_PATH` if the loader cannot find it; the spec
`#include`s the real `<curl/curl.h>` so libcurl dev headers must be installed)

## Gate

```bash
HNL=../host-cli/target/debug/hnl scripts/hnl-gate.sh
```

The gate regenerates `handl-packages/generated/` from `specs/` first, then
typechecks/lints/tests whatever `.hnl` sources exist.
